Инструкция по разворачиванию бота Business
1.	Подключаемся на сервер по ssh

2.	Клонируем проект git clone [адрес ресурса].git [имя папки проекта]
Пример git clone https://github.com/Aibridgevpn/VPN_NEW.git aibridge

3.	Переключаемся на root пользователя: su жмем enter и вводим пароль

4.	Устанавливаем Python venv для возможности создания виртуального окружения
apt update 
apt install python3.11-venv

5.	Выходим из пользователя root:
 	exit или su [имя пользователя]

6.	Переходим в папку с проектом командой :
cd [имя папки]

7.	Создаем виртуальное окружение и активируем его
python3 -m venv venv
source venv/bin/activate

8.	Импортируем библиотеки в виртуальное окружение с помощью файла requirements.txt
pip install -r requirements.txt

9. Загружаем с ПК файл *.env содержащий необходимые переменные

10.	Запускаем бота
nohup python3 [имя исполняемого файла] &python3



11. Открываем планировщик задач командой:
	 crontab -e

12. В конец нужно добавить следующие строки:
*/7 * * * * /home/[имя пользователя]/[папка проекта]/venv/bin/python /home/[имя пользователя]/[папка проекта]/transaction.py >> /home/[имя пользователя]/[папка проекта]/cron.log 2>&1
0 4 * * *  /home/[имя пользователя]/[папка проекта]/venv/bin/python  /home/[имя пользователя]/[папка проекта]/disconnection.py >> /home/[имя пользователя]/[папка проекта]/cron.log 2>&1

13. Выходим предварительно сохранив Ctrl+o Enter Ctrl+x
